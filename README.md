 📸 Shotfile

> Your camera roll of screenshots, finally organized.

Shotfile is an AI-powered screenshot management platform that automatically extracts text from screenshots, categorizes them, and makes them searchable.

Instead of endlessly scrolling through your gallery, Shotfile turns screenshots into an organized, searchable library.

---

## ✨ Features

- 🔍 OCR text extraction from screenshots
- 🧠 AI-powered screenshot categorization
- 📂 Organized screenshot library
- ⭐ Favorites system
- 🔎 Full-text search
- 📊 Dashboard analytics
- 👤 User profiles
- ☁️ Cloud storage support

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/shotfile.git
cd shotfile
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

## 🎯 Problem Solved

People accumulate hundreds of screenshots containing:

- Study notes
- Receipts
- Shopping lists
- Chats
- Important information

Finding them later is difficult.

Shotfile automatically extracts text, categorizes screenshots, and allows instant retrieval through search.
